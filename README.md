# Developing a Java Program
## Description
This project is for the course CS115 Introductino to programming in Java.

It is a simple command line Java program that lets a user input a series of grades, then proceeds to calculate an average grade and parses the value to a letter based grading scale.

## Instructions
With Java installed on your system, run: `java .\Project.java`
